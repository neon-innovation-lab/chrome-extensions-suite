# Neon Innovation Lab - Minimal-Permission Chrome & Edge Extensions

Three lightweight Manifest V3 browser extensions built with minimal permissions (`activeTab`, `storage`, `scripting`), zero ads, and zero cloud tracking.

## 1. FastLLM: AI Search (AEO) Auditor & Markdown Clipper
Audit any website for ChatGPT Search, Perplexity, and Gemini readiness in 1 click:
- Inspects `robots.txt` rules for `GPTBot`, `ClaudeBot`, `PerplexityBot`, and `Google-Extended`
- Checks `/llms.txt` presence and structure
- Audits JSON-LD Schema.org microdata (`Organization`, `Product`, `FAQPage`, `SoftwareApplication`)
- Clips any web page into clean Markdown for LLMs and RAG workflows

- **Install Free (Chrome Web Store):** https://chromewebstore.google.com/detail/fbkcdpjndneocipnafbhofcnnkoaobac
- **Docs & Overview:** https://neoninnovationlab.com/tools/aeo-audit

## 2. ThreadShelf: Local-First Folders & Markdown Export for ChatGPT, Claude & Gemini
Keep your AI prompts organized across all three platforms with 100% local device storage:
- Custom folders across ChatGPT, Claude, and Gemini
- Instant offline search across saved threads
- 1-click export to clean Markdown (`.md`) for Obsidian, Notion, or GitHub
- Zero cloud sync, zero third-party servers reading your conversations

- **Docs & Overview:** https://neoninnovationlab.com/tools/threadshelf

## 3. NeonMaps: B2B Lead & Email Extractor
Lightweight local business discovery for freelance web designers, SEO agencies, and B2B SDRs:
- Search local businesses by niche and city
- Extract public phone numbers, ratings, review counts, and public business emails
- 1-click "No Website" filter to find active local businesses needing a site
- Clean CSV export with simple one-time Pro licensing

- **Docs & Overview:** https://neoninnovationlab.com/tools/gmaps-lead-enricher
